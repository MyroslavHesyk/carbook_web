# CHANGELOG_AI — CarBook Web v2

## Оновлення інтерфейсу
- Повністю перероблено `index.html`: нова авторизація, навігація, мобільна структура, SVG-іконки та семантичні області.
- Повністю перероблено `styles.css`: єдина дизайн-система, контрастна темна навігація, лаймовий акцент, картки, таблиці, графіки, форми, модальні вікна, стани та мобільні breakpoints.
- Додано `assets/icon.svg` та оновлено `manifest.webmanifest`.

## Функціональність
- Переписано `app.js` з розділенням за сценаріями: авторизація, завантаження даних, навігація, CRUD, статистика, нагадування та експорт.
- Додано password reset і password update flow.
- Виправлено помилки з редагуванням `car_id`, сортуванням нагадувань і додаванням автомобілів.
- Додано пагінацію для повного завантаження історії.
- Додано фільтр за автомобілем, CSV та JSON export.
- Експорт повної копії не залежить від активного фільтра автомобіля.
- Додано автоматичне оновлення пробігу автомобіля за новішим записом; збій другорядного оновлення не скасовує успішно збережений запис.
- Додано `core.mjs` для чистих функцій дат, сум, статистики, витрати пального, статусів нагадувань і CSV.

## База даних і безпека
- Повністю оновлено `supabase-schema.sql` для нового чистого Supabase Project.
- `cars.user_id` призначається через `auth.uid()` за замовчуванням.
- Додано RLS-політики для шести таблиць, індекси, перевірки значень і тригер `updated_at`.
- Frontend конфігурація використовує тільки Publishable key / legacy anon key.
- Оновлено `sw.js`: кешуються статичні ресурси, запити до зовнішнього API не перехоплюються.

## Документація та тести
- Створено `README.md`, `DEPLOYMENT.md`, `AUDIT_REPORT.md`.
- Додано `tests/core.test.mjs` — 10 unit tests.
- Усі локальні Node syntax checks і 14 unit/static tests пройшли.
- CSS/HTML статичні перевірки пройшли; браузерний Chromium smoke test заблоковано політикою середовища.

## Не входить у цю версію
- Перенесення старої бази Telegram-бота.
- PDF-звіти, share links, адміністративні розсилки, автоматичні сповіщення, видалення акаунта, офлайн-синхронізація.
- Реальне інтеграційне тестування Supabase — очікує створення Project і введення ключів власником.
